# 21 Blackjack

A Blackjack game built with Python and Streamlit, with an animated casino table.

## Features
- Chip betting, Hit, Stand and Double Down
- Blackjack pays 3:2
- Card deal and flip animations, sound effects and confetti
- Basic-strategy hint button
- Keyboard shortcuts: H, S, D, Enter

## Run locally
    python -m pip install -r requirements.txt
    python -m streamlit run app.py

## Files
- `app.py`: Streamlit app
- `index.html`: the game (HTML, CSS, JavaScript)
- `game.py`: the original terminal version
